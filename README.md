# Pokédex de Bolso

Aplicativo mobile desenvolvido em Flutter e Dart para explorar o universo Pokémon de forma interativa, com consulta de atributos, comparação de Pokémon, desafios e criação de um time de favoritos.

## Funcionalidades

- **Pokédex:** listagem, pesquisa e visualização dos Pokémon.
- **Detalhes:** imagens, tipos e atributos de cada Pokémon.
- **Comparador:** comparação de atributos entre dois Pokémon.
- **Minigame:** desafio interativo para identificar Pokémon aleatórios.
- **Favoritos:** criação de um time com até seis Pokémon.

## Tecnologias

- Flutter e Dart
- PokéAPI — integração com API REST
- HTTP — comunicação com a API
- Git e GitHub — versionamento e colaboração

## Como executar

Pré-requisitos: Flutter SDK, Git e um dispositivo ou emulador compatível.

```bash
git clone <URL_DO_REPOSITORIO>
cd pokedex-de-bolso
flutter pub get
flutter run
```

Documentação da API: https://pokeapi.co/docs/v2
